# Инжиниринговый кейс — карта контента

Страница: `page96490096.html` · CSS `css/emplyflow-engineering-case.css` · JS `js/emplyflow-engineering-case.js` + `js/emplyflow-engineering-case-data.js`

Концепция: **«Проект ищет человека. Человек ищет следующий шаг.»**
Метафора: инженерная схема с пустыми узлами ролей, которая по ходу страницы превращается в работающую команду, а опыт из завершённого проекта возвращается в профили.

Статусы фактов — см. `engineering-case-fact-check.md`. Методология — `engineering-case-hr-methodology.md`.
